Hello! I'm Kedar Awale, a Master's in Computer Science graduate from Florida State University. I hold a Bachelor's degree in Computer Engineering from Savitribai Phule Pune University, where I also earned an Honours Degree in Data Science. I enjoy turning ideas into software that is fast, reliable, and easy to use whether that means crafting clean APIs, building full‑stack web apps, or bringing machine‑learning models into production.

I’m now looking for software engineering roles where I can combine solid engineering practices with a passion for data‑driven solutions. 

Tech stack:
